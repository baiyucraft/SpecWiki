# 环境准备

本页记录本仓库开发和验证的最低环境。具体版本事实以根级配置文件为准。

## 必需工具

| 工具 | 用途 | 事实来源 |
| --- | --- | --- |
| Node.js | 运行 TS CLI、构建脚本和 Vitest | `package.json`、`packages/spec-wiki/package.json` |
| pnpm | 管理 workspace 依赖和脚本 | `package.json` 中的 `packageManager` |
| Rust / Cargo | 构建和测试 `wiki-*` crates | `Cargo.toml` |
| Windows x64 | 当前 npm 包发布目标 | `packages/spec-wiki/package.json` |

## 安装依赖

```bash
pnpm install
```

Rust 依赖由 Cargo 在构建或测试时解析：

```bash
cargo test
```

## 本地配置

- `wiki.dev.yaml` 用于本地 provider、retry、timeout、backoff 等调试参数。
- `.spec/` 保存 UniSpec change artifact。
- `.wiki/` 当前包含长期文档；runtime 产物由 `spec-wiki wiki init` 等命令生成。

## 注意事项

- 本项目仍处于测试开发阶段，不要求保留旧实现兼容层。
- 如果 `pnpm run test` 中的共享 fixture 断言失败，先检查 `tmp/test/storybook` 和 `tmp/test/dagger` 是否存在并处于预期状态。
