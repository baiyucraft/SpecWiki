# 环境准备

## 使用产品

| 工具 | 要求 | 用途 |
| --- | --- | --- |
| Node.js | `>=20.19.0` | 运行 `spec-wiki-lite` |
| npm | 随 Node.js 提供 | 全局安装或安装 tarball |
| Git | 推荐 | 版本控制 `.wiki` 与 `.spec` |
| Codex | 唯一支持的 Agent 宿主 | 发现 `.agents/skills/wiki-*` |

SpecWiki Lite 不限制操作系统和 CPU 架构。安装后确认命令可用：

```bash
npm install -g spec-wiki-lite
spec-wiki-lite --help
```

## 参与仓库开发

根 workspace 使用 `pnpm@10.6.3`：

```bash
pnpm install
pnpm run test
pnpm run lint
pnpm run build
```

主 package 位于 `packages/spec-wiki-lite`。依赖与 Node 版本的当前事实分别来自根级 `package.json` 和 package 自身的 `package.json`。

## 项目目录

初始化目标项目后会得到：

```text
.wiki/
  INDEX.md
.spec/
  changes/
  archive/
.agents/
  skills/
    wiki-*/
```

- `.wiki/` 页面应进入 Git，作为人和 Codex 共享的正式项目知识。
- `.spec/changes/**` 保存进行中的 change；`.spec/archive/**` 保存已验证的历史 change。
- `.agents/skills/wiki-*` 由 package 同步，不应搬到其他宿主目录。

本产品不需要额外本地服务或 provider 配置。开发阶段不要求保留旧版本兼容入口。
