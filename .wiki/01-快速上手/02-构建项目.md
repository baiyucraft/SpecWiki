# 构建项目

本仓库是单一 TypeScript 产品 workspace。根级脚本负责编排 package 测试、构建、合同测试和分发 staging。

## 根级命令

| 命令 | 用途 |
| --- | --- |
| `pnpm run test` | 运行 package 测试、package 构建和根级 Vitest 合同测试 |
| `pnpm run lint` | 对当前源码、测试和脚本执行 ESLint |
| `pnpm run build` | 构建 package，并将发布内容 staging 到 `dist/spec-wiki-lite` |
| `pnpm run pack` | 构建 staging package，再执行 `npm pack` |

## Package 局部验证

```bash
pnpm --dir packages/spec-wiki-lite run test
pnpm --dir packages/spec-wiki-lite run build
```

核心单元测试与源码同目录，重点覆盖：

- asset ownership、幂等更新和自定义页面保留；
- Wiki frontmatter、导航、链接、orphan 与 SSOT 检查；
- change stage、required artifacts、full/pass 证据和归档；
- traversal、绝对路径与 symlink escape；
- CLI 命令闭集、参数和退出码。

## 分发验证

```bash
pnpm run build
pnpm run pack
```

staging package 只应包含 `bin/**`、`dist/**`、`assets/**`、`README.md`、`LICENSE` 和发布 `package.json`。tarball smoke test 应从打包产物安装后执行 `init -> status -> validate -> archive`，不能依赖源码目录中的文件。

## 提交前门禁

```bash
pnpm run test
pnpm run lint
pnpm run build
git diff --check
```

涉及文档时还应检查 frontmatter、相对链接、栏目导航和 current-surface 残留扫描。
