# 构建项目

本仓库同时包含 TypeScript CLI 包和 Rust workspace。根级脚本负责总体入口，子包和 crates 自管局部构建 / 测试。

## 根级命令

| 命令 | 用途 |
| --- | --- |
| `pnpm run build` | 执行 `scripts/build-dist.mjs`，组装发布产物 |
| `pnpm run lint` | 执行 `eslint .` |
| `pnpm run test` | 执行 `scripts/run-tests.mjs` 综合测试 |
| `pnpm run publish` | 执行 `scripts/publish-packages.mjs` 发布流程 |

## Rust 验证

```bash
cargo test
```

Rust workspace 包含：

- `crates/wiki-model`
- `crates/wiki-index`
- `crates/wiki-knowledge`
- `crates/wiki-runtime`

## TypeScript 包验证

`packages/spec-wiki` 自管：

```bash
pnpm --dir packages/spec-wiki run build
pnpm --dir packages/spec-wiki run test
```

## 测试项目验证

页面质量或结构专项优先跑：

```bash
node scripts/run-test-projects.mjs storybook dagger
```

全生命周期验证：

```bash
node scripts/test-wiki-lifecycle.mjs
```
