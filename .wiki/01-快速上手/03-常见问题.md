# 常见问题

## `spec-wiki init` 和 `spec-wiki wiki init` 有什么区别？

`spec-wiki init` 是宿主 bootstrap 入口，负责安装 Codex、Claude、CodeBuddy 等宿主资产。

`spec-wiki wiki init` 是 runtime 入口，负责扫描仓库并生成 repo-local knowledge runtime。

## 为什么 `.wiki/` 里有长期文档，也可能有 runtime 产物？

`.wiki/` 同时承载两类内容：

- 长期文档：根入口、栏目索引、模块指南、对外方法等人工维护页面。
- runtime 产物：`.wiki/pages/**`、`.wiki/.knowledge/**`、`.wiki/.cache/**`、`wiki.metadata.json`。

两者不能混写。长期文档解释项目知识，runtime 产物由 `wiki-runtime` 生命周期维护。

## `pnpm run test` 失败但 `cargo test` 通过怎么办？

先看失败是否来自共享测试项目 fixture。当前部分脚本测试依赖 `tmp/test/storybook`、`tmp/test/dagger` 的状态；如果这些目录缺失或不是预期状态，会触发 reference report / analysis 断言失败。

## 什么时候更新 Wiki？

- 稳定开发规则、公开 CLI、配置边界、模块职责发生变化时，更新 `.wiki/`。
- 临时方案、review 明细和测试报告写入 `.spec/changes/**` 或 `.spec/archive/**`。
- runtime 页面和 cache 由 `spec-wiki wiki init / update / sync / rebuild` 维护。
