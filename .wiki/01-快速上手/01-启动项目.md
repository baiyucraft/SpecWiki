# 启动项目

`spec-wiki` 没有长期运行的本地 Web 服务。日常启动主要是执行 CLI、构建产物或运行测试。

## 从源码运行 CLI

先构建：

```bash
pnpm run build
```

再查看 CLI 帮助或执行命令：

```bash
node dist/spec-wiki/bin/spec-wiki.js --help
```

## 两类 init

| 命令 | 作用 | 是否生成 runtime |
| --- | --- | --- |
| `spec-wiki init --tool codex --repo-root .` | 安装宿主 bootstrap 资产 | 否 |
| `spec-wiki wiki init --repo-root .` | 扫描仓库并初始化 repo-local knowledge runtime | 是 |

本次 Wiki 文档整理是 docs-only pass，不等同于执行 `spec-wiki wiki init`。

## 常用 runtime 命令

```bash
spec-wiki wiki status --repo-root .
spec-wiki wiki query --repo-root . --term "runtime"
spec-wiki wiki update --repo-root .
spec-wiki wiki sync --repo-root .
spec-wiki wiki rebuild --repo-root .
```

需要长流程流式输出时，`init`、`update`、`rebuild` 可使用 `--bridge-stdio`。
