# SpecWiki Lite v0.2.0 发布合同

## 身份

| 项目 | 合同 |
| --- | --- |
| npm package | `spec-wiki-lite@0.2.0` |
| executable | `spec-wiki-lite` |
| runtime | Node.js `>=20.19.0` |
| host | Codex only |
| default locale | `zh` |

## 公开命令

```text
spec-wiki-lite init [path] [--host codex] [--language zh|en] [--force] [--no-codegraph] [--no-aoci] [--json]
spec-wiki-lite status [--json]
spec-wiki-lite show <change-id> [--artifact <artifact>] [--json]
spec-wiki-lite validate <change-id> [--strict] [--json]
spec-wiki-lite update [--force] [--tools] [--json]
spec-wiki-lite archive <change-id>
```

`init` 默认准备 CodeGraph `1.6.0` 和 AOCI-CODE `0.1.0-rc12`。延后或外部未完成时，核心资产可以成功但命令与 `status` 返回 exit `2`。`update --tools` 是修复/升级固定兼容版本的唯一入口。

## 认知职责

- CodeGraph：当前符号、调用链、impact radius、affected tests 与索引健康。
- AOCI：长期职责、强关系、约束、Code Cognition，以及声明 source 后的 Database Cognition。
- `.spec`：变更范围、设计、任务、测试、review 与 verification 证据。
- `.wiki`：经过源码、测试和两种工具交叉验证的长期人类可读文档。

Lite 不复制 CodeGraph 索引或 AOCI 状态机，不读取数据库业务行，不保存凭据。外部二进制与 `.codegraph/.aoci` 本机状态不进入 tarball。

## 制品与验证

发布包只包含 Node CLI、`dist/**`、双语 Wiki 模板、每种语言 8 个 Skills + 20 个 references、README 和 LICENSE。验证至少包含 package/root tests、lint、两层 typecheck、build、pack、tarball fake-tool smoke、真实固定版本 self-bootstrap、Wiki 校验、strict validation 和 `git diff --check`。npm publish、tag 与 merge不属于本 change。
