# spec-wiki v0.2.0 发布合同

本页是 `product-release=spec-wiki v0.2.0` 的唯一长期合同入口。它定义采用的发布承诺和验证边界，不等同于 registry、Git tag、binary checksum 或 staged publish 已经存在。

## 发布身份

| 字段 | 当前值 | Authority |
| --- | --- | --- |
| product release | `spec-wiki v0.2.0` | 本页 |
| decisionStatus | `adopted` | 本页与归档 change evidence |
| architecture baseline | `Repo Wiki 3.0` | [产品基线与设计治理](../06-设计文档/05-产品基线与设计治理.md) |
| distributed-by | `spec-wiki@0.2.0` | `packages/spec-wiki/package.json` |
| staging target | Windows x64 single package | adapter-distribution capability 与 staging tests |

版本数值相同不自动建立映射，数值不同也不自动构成漂移。上表的 `distributed-by` 是显式关系；npm package、Rust crates 与 product release 继续拥有各自 authority。

## 正式 Surface

v0.2.0 product-release contract 包含以下一级 CLI workflow：

- `spec-wiki init`
- `spec-wiki status`
- `spec-wiki update`
- `spec-wiki query <term>`
- `spec-wiki sync`
- `spec-wiki rebuild`

治理维护 surface 还包括 `validate / changes / change / archive`。命令分组、参数、archive dry-run/apply/resume 与退出语义以 [CLI](./00-CLI.md) 为 authority。

Runtime 成功要求提交 `.wiki/.knowledge/**`、official page tree、`wiki.metadata.json` 与可重建 `.wiki/.cache/**` 的正式闭环。Query 只接受非空 `term`，响应合同以 [Runtime 查询合同](../06-设计文档/06-Runtime查询合同.md) 为 authority。

## 制品映射

当前 adopted staging contract 使用 npm 主包 `spec-wiki@0.2.0`，在 staged package 内携带 Windows x64 runtime：

```text
dist/spec-wiki/
  package.json
  README.md
  lib/x64-win32/wiki-runtime.exe
```

Staged manifest 必须声明 `os=["win32"]` 和 `cpu=["x64"]`，且不得恢复 optional platform packages。Rust crate versions 由各自 `Cargo.toml` 独立授权，不要求与 product/npm 版本 lockstep。

## 交付证据

| 证据轴 | 当前要求 | 能否单独证明 released |
| --- | --- | --- |
| implementationEvidence | CLI/runtime/build 与 staging contract 已实现 | 否 |
| verificationEvidence | workspace tests、distribution test、package build、dry-run evidence | 否 |
| releaseEvidence | registry version、Git tag、binary checksum、实际 publish/staged record 等可核验引用 | 是，但必须引用真实证据 |

Contract、manifest、staged package、`npm publish --dry-run`、review report 或 test report 都不自动证明 released。只有 releaseEvidence 具备实际引用且与本合同、制品映射一致时，才能报告已发布；当前没有统一 release evidence registry，因此本页不宣称 `released`。

## 非目标

- 不承诺非 Windows x64 target。
- 不承诺完整 declared authoring、治理平台、复杂宿主 UI 或 richer public query intent。
- 不把 Repo Wiki 3.0 architecture baseline 当作 product semver。
- 不在本页复制 CLI、Runtime query 或 capability 的详细 schema。

## 维护规则

- Surface、target、artifact mapping 或 evidence policy 变化必须先进入 UniSpec change。
- README 和 staged README 只做本合同的公开投影，不成为平行 release authority。
- 历史 release/gap 分析只作为 archive evidence，不回到 current authority。
