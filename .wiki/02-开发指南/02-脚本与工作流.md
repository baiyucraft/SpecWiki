# 脚本与工作流

## 定位

根级 `scripts/*.mjs` 只保留可直接调用的编排入口，内部实现按职责下沉到 `scripts/build/`、`scripts/testing/`、`scripts/tests/` 和 `scripts/templates/`。

脚本布局的可执行说明以 [scripts/README.md](../../scripts/README.md) 为准；本页只沉淀长期工作流语义。

## 主要入口

| 脚本 | 语义 |
| --- | --- |
| `scripts/build-dist.mjs` | dist 组装 |
| `scripts/publish-packages.mjs` | 发布编排 |
| `scripts/run-tests.mjs` | 工作区测试编排 |
| `scripts/run-test-projects.mjs` | 测试项目集 `init` baseline guard |
| `scripts/test-wiki-lifecycle.mjs` | runtime 生命周期验证 |
| `scripts/collect-reference-project-reports.mjs` | reference fidelity 报告收集 |
| `scripts/collect-test-project-analysis.mjs` | 测试项目分析收集 |

## Gate 语义

| 入口 | Gate 类型 | 说明 |
| --- | --- | --- |
| `collect-reference-project-reports.mjs storybook dagger` | primary gate | reference fidelity 是正式 gate 输入，但不替代 formal artifact、restore、query、status gates |
| `run-test-projects.mjs` | baseline guard | 批量项目集 `init` 回归，不等同于全量质量达标承诺 |
| `test-wiki-lifecycle.mjs` | baseline guard | 覆盖 init / status / sync / query / update / rebuild 链路 |

`run-test-projects.mjs` 与 `test-wiki-lifecycle.mjs` 支持 `--jobs <N>` 和 `--json-summary`。并发默认值和输出字段以脚本实现与 `scripts/README.md` 为准。

## 维护要求

- 根级脚本只做编排，不写 core 业务规则。
- 新增跨包验证优先放 `scripts/tests/*.test.ts`。
- 修改 gate 语义时，同步检查 [01-测试与验收](./01-测试与验收.md) 和 `scripts/README.md`。
