# 核心场景

本页是核心场景的人读投影。机器可读 authority 位于 `scripts/testing/core-scenario-acceptance.mjs`，固定合同版本为 `core-scenario-acceptance.v1`；行为证据由 workspace/Rust acceptance tests 提供，不能用本页存在性替代。

## 支持等级

- `supported`：已有公开入口，可由动态 fixture 完整证明当前边界。
- `degraded`：公开入口可给出有界结果，但仍有明确延期能力。

## 场景矩阵

| ID | 支持等级 | 当前公开入口与结果 | 明确边界 |
| --- | --- | --- | --- |
| CS-01 | `supported` | `init/status` 形成正式 knowledge、metadata、页面和可解释 readiness | 自动化只证明概览产物与 evidence，不代表完整架构真相或用户研究 |
| CS-02 | `degraded` | declared `policy/convention` 经 managed edit、`sync/update/query` 进入 `knowledge_declared_hit` | 宿主仍需显式 query；task-aware scope 和宿主 trigger 延期 |
| CS-03 | `degraded` | `query <term>` 通过 canonical `route_groups` 与 `answer` 返回 symbol/path/module 候选及 source refs | 仅 term-only；intent、owner、独立 entrypoint projection 延期 |
| CS-04 | `degraded` | 已知 symbol 的 `index_graph_hit` 提供局部 graph provenance、confidence 与 source refs | 不承诺完整 callers/callees 或穷尽 impact traversal |
| CS-05 | `supported` | 源码变化后 `status` 给出 `needs_update/update`，scoped `update` 后回到 fresh | 自动 PR/branch trigger policy 延期 |
| CS-06 | `degraded` | declared `pitfall` 经 `sync/update/query` 写入正式记录并可追溯 | 没有专用 bug authoring UX，也不自动升级为 policy |
| CS-07 | `degraded` | 结构化 parallel-active declared conflict 生成双方 refs、constrained answer 与 `review_governance` | 不检测任意自然语言规则与源码的语义冲突 |
| CS-08 | `degraded` | declared `policy/convention` 原子写入正式 records 并可 query | 专用 authoring CLI/API 与完整 lifecycle UX 延期 |
| CS-09 | `supported` | B 仅复制正式产物即可恢复 level1；knowledge/projection ready，index missing，fusion degraded，action=rebuild | 不把 level1 伪装成 graph/index ready；源码漂移走 update，页面漂移 fail closed |

## 共同合同

```text
9 个场景记录
  -> acceptance plan 显式声明 fixtures / required gates / guards
  -> 行为 adapter 产生 evidence / failures / diagnostics
  -> knowledge-quality-gates.v2 聚合唯一 decision 与 exit
```

- 公开 query 只消费 `route_groups`、`answer`、readiness、trust、action 和结果内 evidence。
- `.wiki/.knowledge/**`、`wiki.metadata.json` 与 metadata 声明页是 CS-09 的正式恢复输入；`.wiki/.cache/**` 是可重建派生层。
- 一个 failure 只有一个 formal/primary owner；baseline guard 只能引用它。
- `supported/degraded` 状态变化必须先更新机器矩阵与 acceptance evidence，再同步本页。
