# 工作区总览

## 当前结构

```text
packages/spec-wiki-lite/
  assets/
    wiki/
    skills/
  src/
    core/assets/
    core/change/
    core/markdown/
    core/wiki/
    orchestration/init/
    cli.ts
    bin.ts
    index.ts
scripts/
  tests/
```

`packages/spec-wiki-lite` 是唯一产品包。根 workspace 只负责编排 build、test、lint 和发布检查，不拥有第二份业务实现。

## 技术边界

| 项 | 合同 |
| --- | --- |
| 语言 | TypeScript，ES module |
| 执行环境 | Node.js `>=20.19.0` |
| 外部依赖 | `yaml`，用于解析 `.spec` metadata |
| npm 包 | `spec-wiki-lite` |
| 可执行命令 | `spec-wiki-lite` |
| 宿主 | Codex |
| 项目状态 | `.wiki/**` 与 `.spec/**` |

包内调用保持单向：CLI 调用 assets、wiki 和 change；这些模块共享路径安全与 frontmatter 解析，不反向依赖 CLI。

## 事实来源

| 路径 | 用途 |
| --- | --- |
| `package.json` | 根级命令和工具链 |
| `pnpm-workspace.yaml` | workspace 包范围 |
| `packages/spec-wiki-lite/package.json` | 包名、版本、Node.js 要求、发布文件和依赖 |
| `packages/spec-wiki-lite/src/index.ts` | TypeScript 公共 API |
| `packages/spec-wiki-lite/src/**/*.test.ts` | 包内行为验证 |
| `scripts/tests/*.test.ts` | 当前产品面和发布制品验证 |

## 非产品目录

- `dist/**` 是构建结果，不承载源码事实。
- `node_modules/**` 是依赖安装结果。
- `.tmp/**` 只保存一次性调试输出。
- `.docs/**` 只保存登记过的参考材料，不是产品合同。

公开使用方式见[CLI](../04-对外方法/00-CLI.md)，发布身份见[v0.1.0 发布合同](../04-对外方法/02-v0.1.0发布合同.md)。
