## MODIFIED Requirements

### Requirement: 系统必须记录跨模块关系
系统 MUST 在模块树之外记录跨模块关系，并保留这些关系与源码证据之间的关联，以便后续页面生成和查询使用。关系提取 MUST 优先依赖 deterministic 线索，包括 manifest 依赖、导入别名、入口引用和典型前后端或基础设施目录约定，而不是仅靠目录共现或文本巧合。

#### Scenario: 识别模块依赖关系
- **WHEN** 系统在扫描结果中发现跨目录或跨包的显式依赖线索
- **THEN** 系统必须将其记录为跨模块关系
- **THEN** 每条关系必须能够回溯到至少一个来源线索或源码证据

#### Scenario: 在混合仓库中保留基础模块关系
- **WHEN** 仓库同时包含前端、后端和基础设施目录，且存在可确定的入口、依赖或调用线索
- **THEN** 系统必须优先保留这些结构性关系，而不是将模块页全部降级为“无依赖”
- **THEN** 关系证据必须保持 deterministic，可被页面和 query 复用
