# AOCI Explore Procedure

1. Read the official Guide and complete Overview first; confirm that Code Cognition is reliable.
2. Use `verify` / `check` to detect governance drift. Follow upstream Maintain/Recovery when unaligned; never infer AOCI state yourself.
3. Extract only change-relevant responsibilities, strong relations, constraints, confirmed semantics, and unknowns.
4. Write `research/aoci.md` with the Overview/Attestation source, timestamp, facts, inferences, conflicts, and fallback.
5. Do not copy the whole Overview, read database business rows, or persist credential values.
6. AOCI supplies durable semantics; current symbols, call paths, impact, and tests remain CodeGraph plus source/test concerns.
