# Wiki Page Template

Use this structure when adding a stable project knowledge page. Replace every placeholder and remove sections that do not apply.

```markdown
---
title: Page title
description: One-sentence description of the page.
updated: YYYY-MM-DD
owner: Owning team or role
---

# Page title

## Purpose

State what this page owns and who should use it.

## Details

Record verified, durable project knowledge.

## Related sources

List repository paths or authoritative references without duplicating them.
```
