# Page Template

> SpecWiki Lite managed baseline
>
> Keep the relevant sections, replace placeholders with project facts, and link the page from its directory `INDEX.md`.

```markdown
---
title: Page title
description: One sentence describing the page responsibility
updated: YYYY-MM-DD
owner: Owning team or role
---

# Page title

## Scope

State what this page owns and does not own.

## Details

Record verified project knowledge with durable value.

## Sources of truth

List source, configuration, tests, or the unique authoritative page.
```
