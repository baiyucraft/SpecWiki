# Code Commenting

- Explain responsibilities, constraints, defaults, side effects, and exceptional boundaries instead of translating code line by line.
- Document information on exported APIs, configuration, state, and cross-module entry points that types cannot express.
- Place short comments next to complex sequencing, recovery, rollback, and security decisions.
- Remove or update stale comments whenever behavior changes.
