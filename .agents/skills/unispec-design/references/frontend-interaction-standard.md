# 前端开发交互规范

用于 `unispec-design` 在涉及前端界面时约束 `design.md`。本规范是 Skill 内部 reference，不是 change 的 research 产物；不要把全文复制进 `design.md`。

## 一、数据验证与约束

### 1.1 坐标范围限制

- 经度范围：-180° ~ 180°，不得超出此范围
- 纬度范围：-90° ~ 90°，不得超出此范围

### 1.2 数值验证

- 排序序号：必须保证为大于 0 的整数

### 1.3 联系方式格式

- 需兼容中国大陆的手机号、座机号以及客服号码
- 身份证号和电话号码需使用正则进行格式校验（Form.Item rules pattern）

## 二、查询与分页逻辑

### 2.1 多条件查询

- 点击查询按钮时，必须从第 1 页开始查询
- 查询时必须携带所有多条件参数
- 点击分页查询时，也需要携带多条件参数
  - 修改查询条件未点击查询时，翻页使用上次查询条件
  - 点击查询后翻页使用新查询条件
- 前端自行过滤数据时，搜索需支持大小写模糊匹配（使用 toLowerCase() 或正则）
- 多条件查询时，input 输入框按 Enter 键应触发查询事件
- 点击重置按钮时，仅重置查询条件，不重置查询结果

### 2.2 删除后的数据查询

- 批量删除后：需要从第 1 页开始重新查询
- 单个删除后：默认查询当前页数据
  - 如果当前页数据为空，自动查询前一页数据

### 2.3 分页与查询布局

- 分页器 Pagination 应固定在页面底部
- 多条件查询区域应固定在页面顶部
- 无数量限制时需提供分页和搜索功能
- 带列表展示时需提供刷新按钮

## 三、表单交互与验证

### 3.1 Input 输入框

- Placeholder 提示：`请输入 + label 的名称`
- 必填项报错：`请输入 + label 的名称`
- 必填标识：必填字段使用红色 * 号标识
- 长度限制：输入框需设置 maxLength 属性，未指定时默认 255（Form.Item 内若已通过 rules max 限制则不算问题）
- 交互支持：支持一键清除输入内容

### 3.2 Select 选择器

- Placeholder 提示：`请选择 + label 的名称`
- 必填项报错：`请选择 + label 的名称`
- 搜索功能：下拉选择时需支持模糊搜索

### 3.3 表单提交

- 提交时必须校验必填项
- 校验不通过时需标红提示，实时触发校验
- 未填写完整时不调用接口
- 涉及接口调用的确定 / 提交按钮需加防抖（添加 loading 或 disabled 状态）

### 3.4 数据编辑

- 针对不可编辑的字段，需要置灰显示

### 3.5 文件上传

- 上传附件处需注明格式及要求说明文字

### 3.6 日期选择

- 日期选择框建议提供快速选择功能（使用 RangePicker 的 ranges 配置）
- 日期范围选择需限制起止逻辑（结束时间不能早于开始时间）

## 四、UI 交互与布局

### 4.1 弹窗与模态框

- 删除数据时，必须弹窗提示确认
- 点击 Modal 弹窗背景，弹窗不消失
- 按钮布局：取消按钮在左，确认 / 完成按钮在右

### 4.2 按钮交互

- 未实现的按钮点击时，需要给出明确的提示
- 不允许点击无反应
- 未勾选数据时，批量操作按钮需灰显（disabled 绑定选中状态）
- 图标类操作按钮需添加 title 属性

### 4.3 数据展示

- 时间显示格式：必须处理为 `YYYY-MM-DD HH:mm:ss`
  - 不要显示 UTC 格式
  - 不要显示时间戳格式
- 空值处理：直接展示空，不要展示成 `-`、`暂无` 等
- 数据过长时需添加 ellipsis 或 overflow:hidden，防止样式错乱
- 文本内容显示需添加 Tooltip 或原生 title 提示
- 表格展示需添加 Loading 加载提示
- 搜索结果为空时需有空状态占位图和描述

### 4.4 分辨率适配

- 界面需适配 1280×720 / 1920×1080 分辨率

### 4.5 操作反馈

- 操作类接口（增删改）成功时需添加 message.success/info 提示

## 五、输入框全局限制

### 5.1 空格控制

- 不可以空格开头
- 不可以空格结尾

### 5.2 输入触发

- 多条件查询时，input 输入框按 Enter 键需要触发查询事件
- 支持一键清除输入内容
